What’s a clean way to debounce a search box?

Wait until the person stops typing, then search. A tiny helper keeps it tidy:

function debounce(fn, ms = 250) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), ms);
  };
}

Wrap your input handler with it. Around 250 ms feels like a natural typing pause.

What’s inside

Small on screen. Thorough underneath.

  • Your accounts, your models

    Sign in once in a normal window and stay signed in. Without signing in, QChat chats as a ChatGPT guest.

  • ChatGPT or Gemini

    Switch with /chatgpt or /gemini. Each chat keeps the provider it started on, and its tab shows the logo.

  • Real glass

    The desktop really is blurred behind it, and clicks pass straight through the empty space around the bar.

  • Files, paste and drop

    Attach up to ten files, paste images, or drop anything onto the chat. Replies show image, audio and video previews.

  • Keyboard first

    / for commands, CtrlK for the menu, CtrlF to find, and CtrlAltQ to ask about selected text.

  • Kept on your PC

    Up to 50 chats are saved locally. CtrlShiftN starts a temporary chat that stays out of history entirely.

Make it yours

Twenty looks, one material.

Pick a look, then tune glass opacity, density, font and motion in Settings. An optional guard keeps text at 4.5:1 contrast on any wallpaper.

Install

Up and running in a minute.

  1. 01

    Download the installer

    One file, with the WebView2 runtime included. Nothing else to install.

  2. 02

    Run it

    It installs for your Windows user and adds a Start menu shortcut. Upgrading keeps your settings, chats and sign-in.

  3. 03

    Press AltQ

    Sign in from Settings or the tray icon, and you’re set. Type /keys to see every shortcut.
